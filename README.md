# kodanikupalk.ee/kalkulaator koodivara

Siin on kodanikupalga rahalise mõju veebikalkulaatori tööks vajalik koodivara. Alustatud sellest hetkest, kui loodi mobiilisõbralik vaade.

Kaustas [muudatused](./muudatused/) on kõikide muudatuste kirjeldused alates js koodi ümberkirjutamisest claude.ai abil.
